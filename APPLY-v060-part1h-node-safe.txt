Part 1H — безопасный Node-установщик

Старый PowerShell-установщик НЕ использовать.

Почему Node:
проект уже использует npm/node, поэтому не зависит от версии PowerShell,
его кодировки или особенностей parser.

1. Распаковать все файлы ZIP в:
   D:\job\it\msm-app

2. Сначала только проверка:
   node .\apply-v060-part1h-safe.cjs --check

3. Если четыре строки OK:
   node .\apply-v060-part1h-safe.cjs

4. Затем:
   git diff --check
   cd .\frontend
   npm run build

Установщик:
- проверяет наличие Part 1F и Part 1G;
- проверяет нужные маркеры App.tsx;
- делает backup App.tsx;
- добавляет invoiceSubmissionQueue.ts;
- добавляет восстановление pending-отправок после запуска;
- заменяет finishInvoice на безопасную постановку в локальную очередь.
