v0.6.0 Part 1M-C — возврат задачи ЭТРН менеджеру

Требует:
- Part 1L v4
- Part 1M-A (ReturnToManagerPanel)
- Part 1M-B (возврат доверенности)

Что делает:
- не создаёт второй блок возврата;
- расширяет существующий общий блок:
  POWER_OF_ATTORNEY + ETRN;
- кнопка «Вернуть менеджеру» доступна при NEW и IN_PROGRESS;
- используется тот же выбор причины/комментария;
- возвращается текущая задача;
- данные и вложения не очищаются;
- остальные типы задач не затрагиваются.

Распаковать ZIP в:
D:\job\it\msm-app

Проверка:
node .\apply-v060-part1m-c-etrn-return.cjs --check

Если всё OK:
node .\apply-v060-part1m-c-etrn-return.cjs

Затем:
git diff --check
cd .\frontend
npm run build

После этого следующий этап:
менеджер должен видеть возвращённую задачу как «Нужно исправить»,
видеть причину/комментарий и открывать её сразу для редактирования.
