v0.6.0 Part 1N-G1 v3 — возврат счёта менеджеру + ссылки в списке сделок

Исправление v3:
- установщик больше НЕ ожидает, что в task.update уже есть assigneeId;
- сам находит data: { ... } внутри tx.task.update;
- если assigneeId есть — заменяет на managerId сделки;
- если assigneeId отсутствует — добавляет его;
- проверен на 3 вариантах локального backend-кода.

Функционально:

1. Возврат запроса на создание счёта
Та же ISSUE_CLIENT_INVOICE task:
- status = NEED_DATA
- assigneeId = managerId сделки
- новая задача не создаётся
- бухгалтер остаётся actorId возврата

2. Список «Сделки»
Внутренний номер ЗК показывается всегда.

3. ЗК — ссылка на конкретную сделку.

4. Все активные задачи сделки показываются ссылками.
DONE / CANCELLED не показываются.

5. Возвращённый запрос на счёт имеет ссылку:
«Открыть задачу и исправить →»

Prisma migration НЕ нужна.
