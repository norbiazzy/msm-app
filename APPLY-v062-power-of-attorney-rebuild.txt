v062 — пересборка доверенности

Менеджер создаёт:
- Поставщик / завод
- На кого доверенность — большое поле
- Что получаем — большое поле
- Комментарий для бухгалтерии
- Комментарий для себя — сохраняется в сделке
- Дополнительные документы
- Срочно

Убрано из формы доверенности:
- выбор организации
- ручной входящий счёт
- дата
- водители
- комментарий по водителю

Пока тестируем — поля доверенности не делаем обязательными.

Бухгалтер видит:
- Поставщик / завод
- актуальный основной счёт клиента, если есть
- входящий счёт поставщика, если есть
- На кого доверенность
- Что получаем
- Комментарий для бухгалтерии
- документы
- СРОЧНО

Возврат:
- бухгалтер может вернуть доверенность менеджеру;
- возвращается эта же задача;
- менеджер получает те же рабочие поля;
- причина/комментарий возврата показываются, если backend их отдаёт;
- старые документы сохраняются;
- новые прикладываются и видны бухгалтеру;
- повторная отправка не создаёт новую задачу.

Завершение бухгалтером:
- номер доверенности — обязателен;
- файл готовой доверенности — обязателен;
- комментарий бухгалтера — необязателен.

Результат сохраняется в Task.details:
- poaNumber
- accountantComment

Новая Prisma migration не нужна: Task.details уже существует.

  в уже существующее Task.details.
