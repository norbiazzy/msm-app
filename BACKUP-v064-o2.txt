Backup before v064-O2

Этот набор НЕ использует git reset / checkout / clean.

Backup сохраняет только файлы, которые меняет O2:
- frontend/src/App.tsx
- frontend/src/styles.css

Дополнительно сохраняются:
- git status
- git diff этих двух файлов
- SHA-256 контрольные суммы

1. Сначала сделать backup:

cd D:\job\it\msm-app
node .\backup-before-v064-o2.cjs

Должно быть:
BACKUP OK

Backup будет лежать локально:
D:\job\it\msm-app\.backups\before-v064-o2-YYYYMMDD-HHMMSS

2. Потом можно ставить O2.

3. Если O2 не понравится или появится проблема:

cd D:\job\it\msm-app
node .\restore-before-v064-o2.cjs --yes

Перед восстановлением restore сам дополнительно сохранит
текущее состояние в .backups\before-restore-...

После отката:

cd .\frontend
npm run build
