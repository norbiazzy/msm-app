v064-K — быстрый поиск задач

Требует v064-J.

Добавляет строку поиска над фильтрами.
Ищет по:
- номеру ЗК;
- клиенту;
- названию задачи;
- описанию;
- МСМ / СТ / ИП;
- номеру текущего счёта;
- поставщику в supplierPurchase/payload.

На мобильном кнопка Поиск в нижней панели,
если пользователь находится в Задачах,
фокусирует поиск задач; в Сделках — поиск сделок.

Установка:

cd D:\job\it\msm-app

node .\apply-v064-k-task-search.cjs --check

Если OK:

node .\apply-v064-k-task-search.cjs

git --no-pager diff --check

cd .\frontend
npm run build

После сборки:

cd ..
node .\audit-v064-k-task-search.cjs
