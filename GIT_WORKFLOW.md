# Git workflow для MSM App

## Один раз

1. Установить Git for Windows.
2. Сохранить локальный `backend/.env` — он не должен попадать в Git.
3. Создать на GitHub пустой **Private** репозиторий, например `msm-app`.
   Не добавлять README, .gitignore или License при создании: они уже есть в проекте.
4. В PowerShell из корня проекта выполнить:

```powershell
.\scripts\connect-github.ps1 -RepoUrl "https://github.com/ВАШ_ЛОГИН/msm-app.git"
```

При первом push Git Credential Manager может открыть браузер для входа в GitHub.

## Обычное обновление проекта

Из корня проекта:

```powershell
.\scripts\update.ps1
```

Скрипт:
- получает изменения через `git pull --ff-only`;
- обновляет npm-зависимости;
- обновляет Prisma Client;
- применяет миграции, если они появились.

`backend/.env` при обновлении не трогается.

## Проверить состояние

```powershell
git status
```

## Правило версий

- `0.1.x` — исправления и небольшие дополнения текущего MVP;
- `0.2.0` — новый крупный блок функций;
- `1.0.0` — первая стабильная рабочая версия.

Каждый выпуск помечается Git-тегом, например `v0.1.2`.
