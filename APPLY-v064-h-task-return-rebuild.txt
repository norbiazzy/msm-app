v064-H — Task Detail + Return Rebuild

Пересобирает визуально:
- открытую задачу;
- шапку задачи;
- ссылку на сделку;
- блок данных менеджера;
- документы;
- действия бухгалтера;
- возврат менеджеру;
- состояние Нужно исправить;
- редактирование той же задачи;
- повторную отправку;
- mobile.

Бизнес-логика НЕ меняется:
- используется та же задача;
- старые данные сохраняются;
- старые документы сохраняются;
- существующая отправка/загрузка файлов остаётся;
- API/backend не меняются.

Установка:

cd D:\job\it\msm-app

node .\apply-v064-h-task-return-rebuild.cjs --check

Если OK:

node .\apply-v064-h-task-return-rebuild.cjs

git --no-pager diff --check

npm run build

cd ..
node .\audit-v064-h-task-return-rebuild.cjs
