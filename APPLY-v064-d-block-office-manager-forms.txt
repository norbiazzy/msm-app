v064-D — Block Office Manager Forms

Что меняется визуально:
- новая сделка / запрос счёта;
- поля и textarea;
- сегментированные переключатели;
- срочность;
- прикрепление файлов;
- форма доверенности;
- карточки доверенностей;
- формы закупки/поставщика;
- структурированные поля ЭТРН;
- возврат и повторная отправка менеджера;
- mobile.

Логика, API и backend не меняются.
Требуется v064-A+B.

Установка:

cd D:\job\it\msm-app

node .\apply-v064-d-block-office-manager-forms.cjs --check

Если OK:

node .\apply-v064-d-block-office-manager-forms.cjs

git --no-pager diff --check

cd .\frontend
npm run build

После сборки:

cd ..
node .\audit-v064-d-block-office-manager-forms.cjs
