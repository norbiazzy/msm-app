v064-J — утверждённый список задач

Это уже не косметика: старые визуальные группы
«В работе / Новые / Нужно исправить» заменяются на одну ленту.

Новый экран:
- роль + количество активных;
- фильтры Все / В работе / Новые / Нужно исправить;
- одна компактная лента;
- заметный номер ЗК;
- МСМ / СТ / ИП;
- номер текущего счёта клиента, если он есть;
- один статус справа;
- тихая дата;
- компактная строка причины возврата;
- прогресс отправки файлов остаётся на задаче;
- выполненные остаются отдельным сворачиваемым блоком.

Источник для номера счёта:
deal.invoices.find(invoice => invoice.isCurrent) ?? deal.invoices[0]

Логика задач/API/backend не меняется.
