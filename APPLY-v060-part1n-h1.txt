v0.6.0 Part 1N-H1 — навигация задача -> сделка

Что добавляет:

1. В списке «Задачи»
строка:
Клиент · ЗК-123

Теперь ЗК-123 кликабелен.
Нажатие открывает конкретную сделку:
#deal/<dealId>

2. В открытой задаче
сверху появляется компактная ссылка:
ЗК-123 · Клиент · Открыть сделку →

То есть навигация теперь работает в обе стороны:
Сделка -> задача
Задача -> сделка

Backend не меняется.
Prisma migration не нужна.

Установка:
1. Распаковать в:
D:\job\it\msm-app

2. Проверка:
node .\apply-v060-part1n-h1-task-to-deal-links.cjs --check

3. Если OK:
node .\apply-v060-part1n-h1-task-to-deal-links.cjs

4. Затем:
git diff --check

5. Frontend:
cd .\frontend
npm run build
