MSM v0.5.5 — структура сделки

1. Положите update-v055-deal-structure.patch в корень D:\job\it\msm-app
2. Проверка:
   git apply --check .\update-v055-deal-structure.patch
3. Применение:
   git apply .\update-v055-deal-structure.patch
4. Проверка diff:
   git diff --check
5. Сборка:
   npm run build

Prisma migration не нужна.

Основные изменения:
- новая компактная структура карточки сделки;
- внутренний ЗК и дата создания менее заметны;
- крупно показан текущий наш счёт;
- сумма счёта, входящая сумма и дата доставки редактируются по нажатию и могут копироваться;
- поставщик, статус счёта и статус оплаты видны сразу;
- клиент оформлен отдельным органичным блоком с редактированием через •••;
- у счёта убрана кнопка •••;
- «Скорректировать» и «Всё верно» стоят в одной строке;
- в корректировке: от кого выставляем, комментарий, основной входящий, дополнительные документы;
- сумма и дата доставки убраны из меню корректировки;
- при добавлении поставщика можно выбрать уже прикреплённый входящий счёт сделки и/или добавить другой;
- суммы форматируются разрядами во время ввода;
- при смене СТ/МСМ/ИП во время корректировки старая версия счёта сохраняет свой тип продавца в истории.
