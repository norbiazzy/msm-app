MSM v0.5.8 — следующий этап + стабилизация

Требование: сначала должен быть применён v0.5.7.

Что входит:
1. Исправление возврата запроса «Нет условий»:
   - повторная отправка теперь сохраняет условия и возвращает ту же задачу бухгалтерии;
   - если причина была «Нет условий», отправить задачу без заполненных условий больше нельзя;
   - если причина «Нет входящего счёта», повторная отправка без входящего также блокируется.

2. Бухгалтер не может завершить задачу на счёт без файла готового счёта.
   Проверка есть и во frontend, и в backend.

3. Корректировку счёта можно отозвать, пока бухгалтер не взял её в работу.
   При отзыве задача отменяется, статус счёта возвращается назад, файлы этой корректировки убираются из сделки.
   Если при корректировке меняли СТ/МСМ/ИП, это изменение также откатывается.

4. Оплата с остатка:
   - уже оплаченную закупку можно отправить бухгалтеру на уточнение фактически списанной суммы;
   - бухгалтер получает отдельную задачу и подтверждает фактическую сумму;
   - если после корректировки остаётся недоплата, менеджер может отправить остаток в оплату отдельной задачей.

5. Новый раздел «Доверенности»:
   - менеджер создаёт запрос на доверенность из карточки сделки;
   - поля: поставщик/завод, от какой организации, на кого, входящий счёт, дата, что получаем, комментарий, срочность;
   - можно приложить документы;
   - бухгалтер получает отдельную задачу, берёт её в работу, прикладывает готовую доверенность и завершает;
   - готовая доверенность видна и открывается из сделки.

6. Добавлен универсальный Task.payload (Json) — фундамент для следующих этапов, включая ЭТрН.

ПРИМЕНЕНИЕ

cd D:\job\it\msm-app
