MSM v0.6.0 Part 1C — локальный черновик формы «Счёт готов»

Что меняется:
- номер счёта и сумма автоматически сохраняются локально;
- выбранные файлы сохраняются в IndexedDB;
- после перезагрузки/повторного открытия задачи черновик восстанавливается;
- перед фоновой отправкой файлы больше не очищаются заранее;
- черновик удаляется только после успешного createInvoice;
- если бухгалтер осознанно возвращает задачу менеджеру, локальный черновик этой задачи очищается.

ВАЖНО:
Этот этап защищает заполненные данные, но пока НЕ делает само приложение полноценным offline/PWA.
Если сайт недоступен без сети, после восстановления соединения и открытия той же задачи данные должны восстановиться.

Применение:

cd D:\job\it\msm-app

git status --short

git apply --check .\update-v060-part1c-invoice-draft.patch

Если проверка прошла без ошибок:

git apply .\update-v060-part1c-invoice-draft.patch

git diff --check

npm run build

Тест:
1. Открыть бухгалтерскую задачу «Выставить счёт» и взять её в работу.
2. Заполнить номер и сумму.
3. Прикрепить PDF/файл.
4. НЕ нажимать «Счёт готов».
5. Обновить страницу браузера или закрыть и снова открыть эту задачу.
6. Номер, сумма и файл должны восстановиться.
7. Затем нажать «Счёт готов» и проверить обычную отправку.
8. После успешной отправки черновик этой задачи должен быть удалён.

Отдельный следующий этап: PWA/offline shell, чтобы сам интерфейс приложения не исчезал без интернета.
