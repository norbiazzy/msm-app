MSM v0.6.0 — часть 1: счёт

Что меняется:
- убрано отдельное поле «Условия / Наценка» из создания запроса и повторной отправки;
- условия указываются в «Комментарий бухгалтерии»;
- при возврате с причиной «Нет условий» нельзя повторно отправить задачу, пока комментарий бухгалтерии не изменён;
- внутри сделки явно видно, что запрос вернула бухгалтерия;
- «Реквизиты / дополнительные документы» вместо общего названия вложений;
- бухгалтер не может завершить задачу без номера готового счёта и файла;
- номер счёта автоматически пробуем взять из имени прикреплённого файла;
- в задаче бухгалтерии показаны автор запроса и дата/время;
- новый счёт, ожидающий проверки менеджером, подсвечивает сделку;
- после «Всё верно» подсветка исчезает, кнопка «Скорректировать» остаётся;
- миграция Prisma не требуется.

Применение:
1) git apply --check .\update-v060-part1-invoice.patch
2) git apply .\update-v060-part1-invoice.patch
3) git diff --check
4) npm run build

Если git apply --check или npm run build выдаст ошибку — не продолжать, прислать полный вывод.
