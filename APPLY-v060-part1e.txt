v0.6.0 Part 1E — индикатор состояния сети

Что делает:
- при потере сети показывает «Нет подключения к сети» и «Ждём восстановления соединения…»;
- при восстановлении показывает «Сеть восстановлена» на 2,5 секунды;
- загрузки, API и черновики не меняет.

Применение:
cd D:\job\it\msm-app
git apply --check .\update-v060-part1e-network-status.patch

Если ошибок нет:
git apply .\update-v060-part1e-network-status.patch
git diff --check
npm run build

Тест:
1. Открыть приложение.
2. Отключить интернет — плашка появляется без F5.
3. Включить интернет — появляется «Сеть восстановлена».
4. Через 2,5 секунды плашка исчезает.
