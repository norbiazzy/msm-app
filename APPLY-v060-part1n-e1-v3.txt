v0.6.0 Part 1N-E1 v3 — структурированные поля доверенности и ЭТРН

Исправление v3:
- установщик больше НЕ ищет точную строку `description` в schema.prisma;
- сам находит `model Task { ... }`;
- добавляет `details Json?` непосредственно в модель Task;
- работает даже если локальная модель Task уже отличается от GitHub;
- проверен на моделях Task с другим форматированием и даже без поля description.

Функционально остаётся то же:
Доверенность:
- Поставщик / завод
- От какой организации
- На кого доверенность
- № входящего счёта
- Дата
- Что получаем
- Водитель / водители
- Комментарий по водителю

ЭТРН:
- № доверенности
- Покупатель
- Перевозчик
- Контакты перевозчика
- Логист
- Телефон логиста
- Водитель
- Машина
- Прицеп
- Адрес погрузки
- Адрес выгрузки
- Дата перевозки
- Груз / материал

Все поля пока необязательные.

Установка:
1. Распаковать ZIP в:
D:\job\it\msm-app

2. Проверка:
node .\apply-v060-part1n-e1-v3-structured-poa-etrn.cjs --check

3. Если OK:
node .\apply-v060-part1n-e1-v3-structured-poa-etrn.cjs

4. Затем:
git diff --check

5. Prisma:
cd .\backend
npx prisma migrate deploy
npx prisma generate
npm run build

6. Frontend:
cd ..\frontend
npm run build
