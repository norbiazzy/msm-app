Part 1H — безопасный установщик

Почему не patch:
App.tsx уже сильно изменён предыдущими этапами, и обычные unified diff hunks
ломаются на смещениях. Этот установщик работает по устойчивым маркерам.

1. Скопировать ОБА файла в D:\job\it\msm-app:
   - apply-v060-part1h-safe.ps1
   - invoiceSubmissionQueue.part1h.tmp

2. Проверка без изменений:
   powershell -ExecutionPolicy Bypass -File .\apply-v060-part1h-safe.ps1 -CheckOnly

3. Если показывает все OK:
   powershell -ExecutionPolicy Bypass -File .\apply-v060-part1h-safe.ps1

4. Проверить:
   git diff --check
   cd frontend
   npm run build

Скрипт сам делает backup App.tsx с timestamp.
