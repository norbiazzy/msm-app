v0.6.0 Part 1K — «Ждём сервер» + auto-retry

Требует уже установленные:
- Part 1I («Ждём сеть»)
- Part 1J (контроль /api/health)

Что делает:
- если интернет есть, но запрос падает именно как ошибка соединения,
  фоновая отправка переходит в WAITING_SERVER;
- карточка показывает «Ждём сервер…» + spinner;
- бизнес-ошибки сервера (обычные 4xx/5xx ответы) автоматически не повторяются;
- успешный /api/health отправляет событие фоновой очереди;
- очередь сама повторяет WAITING_SERVER после восстановления backend.

Распаковать в:
D:\job\it\msm-app

Проверка:
node .\apply-v060-part1k-waiting-server.cjs --check

Если всё OK:
node .\apply-v060-part1k-waiting-server.cjs

Затем:
git diff --check
cd .\frontend
npm run build

Тест:
1. Backend запущен.
2. Начать отправку файла/счёта.
3. Во время отправки остановить backend на 3002, не выключая интернет.
4. Карточка должна перейти в «Ждём сервер…».
5. Запустить backend снова.
6. После успешного health-check отправка должна продолжиться сама.
