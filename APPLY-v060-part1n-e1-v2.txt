v0.6.0 Part 1N-E1 v2 — структурированные поля доверенности и ЭТРН

Добавляется Task.details Json? (JSONB), поэтому требуется Prisma migration.

ДОВЕРЕННОСТЬ:
- Поставщик / завод
- От какой организации
- На кого доверенность
- № входящего счёта
- Дата
- Что получаем
- Водитель / водители
- Комментарий по водителю

ЭТРН:
- № доверенности
- Покупатель
- Перевозчик
- Контакты перевозчика
- Логист
- Телефон логиста
- Водитель
- Машина
- Прицеп
- Адрес погрузки
- Адрес выгрузки
- Дата перевозки
- Груз / материал

Все поля пока необязательные.

При возврате:
- менеджер получает те же details;
- редактирует их;
- добавляет документы при необходимости;
- повторно отправляет ту же Task;
- бухгалтер видит тот же структурированный блок.

Установка:

1. Распаковать ZIP в:
D:\job\it\msm-app

2. Проверка:
node .\apply-v060-part1n-e1-v2-structured-poa-etrn.cjs --check

3. Применить:
node .\apply-v060-part1n-e1-v2-structured-poa-etrn.cjs

4. Проверить diff:
git diff --check

5. ОБЯЗАТЕЛЬНО применить миграцию:
cd .\backend
npx prisma migrate deploy
npx prisma generate
npm run build

6. Frontend:
cd ..\frontend
npm run build
