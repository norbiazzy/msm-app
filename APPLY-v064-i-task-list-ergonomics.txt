v064-I — Task List Ergonomics

Что делает:
- убирает внутренний дубль слова «Задачи»:
  «Задачи бухгалтерии» -> «Бухгалтерия»
- делает карточки задач чище и плотнее;
- усиливает номер сделки;
- улучшает статусные плашки;
- улучшает блок «Нужно исправить»;
- добавляет аккуратный визуальный слот под номер счёта и продавца (МСМ / СТ / ИП), если эти данные уже выводятся карточкой;
- сохраняет текущую логику.

Установка:

cd D:\job\it\msm-app

node .\apply-v064-i-task-list-ergonomics.cjs --check

Если OK:

node .\apply-v064-i-task-list-ergonomics.cjs

git --no-pager diff --check

cd .\frontend
npm run build

После сборки:

cd ..
node .\audit-v064-i-task-list-ergonomics.cjs
