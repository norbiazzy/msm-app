v0.6.0 Part 1N-B2 — исправление возвращённой оплаты поставщику

Требует:
- Part 1L v4
- Part 1M-A
- Part 1N-B1

Что делает:
- при PAY_SUPPLIER + NEED_DATA менеджер получает редактор;
- можно изменить:
  * поставщика;
  * номер входящего счёта;
  * сумму к оплате;
  * комментарий;
  * срочность;
- сумма одновременно обновляет:
  * incomingInvoiceAmount;
  * requestedAmount;
  поэтому бухгалтер не увидит старую сумму;
- после сохранения эта же Task меняется NEED_DATA -> NEW;
- assigneeId -> null;
- SupplierPurchase остаётся тем же;
- файлы и остальные связи остаются;
- новая Task НЕ создаётся;
- вся операция проходит одной backend-транзакцией;
- AuditEvent SUPPLIER_PAYMENT_TASK_RESUBMITTED;
- Prisma migration не требуется.

ВАЖНО:
Файлы на этом этапе сохраняются как есть.
Следующим шагом можно добавить менеджеру возможность
доложить новый входящий счёт/документы перед повторной отправкой,
с прогрессом прямо в карточке задачи по уже сделанной схеме.
