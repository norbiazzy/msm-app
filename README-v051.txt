MSM v0.5.1 — карточка сделки, требующая действия менеджера

1) Положите update-v051-manager-action.patch в D:\job\it\msm-app
2) Проверка:
   git apply --check .\update-v051-manager-action.patch
3) Применение:
   git apply .\update-v051-manager-action.patch
4) Проверка:
   git diff --check
   npm run build

Что меняется:
- Сделки, которые бухгалтерия вернула с NEED_DATA, поднимаются выше обычных.
- В списке сделок сразу видны причина и комментарий бухгалтерии.
- Вместо «Ожидаем счёт» показывается «Нужны данные».
- Вместо «Активных задач: 1» показывается «Исправить и повторно отправить →».
- Добавлен заметный оранжевый акцент в светлой и тёмной теме.
- Backend списка сделок отдаёт последнее событие INVOICE_REQUEST_RETURNED для отображения причины.

Миграция Prisma не нужна.
