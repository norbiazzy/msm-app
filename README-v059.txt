v0.5.9 — stabilization patch

Основан на msm-current-full-snapshot.txt, который был прислан после v0.5.8.

Что исправляет:
1. Типизирует payload доверенностей внутри PowerOfAttorneyBlock, чтобы JSON-поля не рендерились как unknown.
2. Убирает причину текущей TS18047/ReactNode-цепочки вокруг payload.invoiceNumber.

4. Поле условий принимает запись вида -7%, +4%, -7, +4.
5. Backend повторно проверяет, что значение условий является числом.

Новых функций и миграций Prisma нет.
