MSM v0.6.0 — часть 1A: возврат запроса на счёт

Основа: msm-part1a-current.zip, присланный после чистого npm run build.

Что меняется:
1. Когда бухгалтер возвращает запрос на счёт, задача получает NEED_DATA и больше не остаётся назначенной на бухгалтера.
2. Менеджер внутри сделки видит причину именно по текущей возвращённой задаче, без подмешивания старой причины из истории.
3. Повторная отправка использует ту же активную задачу и переводит её обратно в NEW.
4. Для причины «Нет условий» условия указываются в поле «Комментарий бухгалтерии».
5. Отдельные поля «Условия / Значение» убраны именно из формы повторной отправки возвращённого запроса.
6. Старые marginMode/marginValue в сделке при повторной отправке не стираются, если новая форма их не передаёт.
7. Миграция Prisma не требуется.

ВАЖНО:
Не применять старый update-v060-part1-invoice.patch.
Использовать только update-v060-part1a-invoice-return.patch из этого архива.

Применение из D:\job\it\msm-app:

git apply --check .\update-v060-part1a-invoice-return.patch

Если ошибок нет:

git apply .\update-v060-part1a-invoice-return.patch
git diff --check
npm run build

Если git apply --check или npm run build выдаст ошибку — не делать другие откаты/патчи, а прислать полный вывод.
