v062 — аудит формы «Сделать доверенность»

Ничего не изменяет.

Проверяет:
- создание запроса;
- что видит бухгалтер;
- возврат менеджеру;
- завершение доверенности;
- связанные API/типы.

Запуск:

cd D:\job\it\msm-app
node .\audit-v062-power-of-attorney-fields.cjs

После вывода собираем один патч под утверждённую схему.

Менеджер:
- Поставщик / завод
- На кого доверенность (большое поле)
- Что получаем (большое поле)
- Комментарий для бухгалтерии
- Комментарий для себя
- Дополнительные документы
- Срочно

Бухгалтер:
- Поставщик / завод
- актуальный основной счёт клиента, если есть
- входящий счёт, если есть
- На кого доверенность
- Что получаем
- Комментарий для бухгалтерии
- документы
- СРОЧНО

Возврат:
- та же задача
- те же рабочие поля
- причина + комментарий бухгалтера
- старые файлы сохраняются, новые добавляются

Завершение:
- номер доверенности
- готовый файл доверенности
- комментарий бухгалтера

Убираем из доверенности:
- организацию
- номер входящего счёта как ручное поле
- дату
- водителя / водителей
- комментарий по водителю
