v0.6.0 Part 1J — статус backend-сервера

Что делает:
- интернет может быть доступен, но backend временно недоступен;
- приложение проверяет /api/health;
- после 2 последовательных неудач показывает:
  «Сервер временно недоступен · Повторяем подключение…»;
- при восстановлении показывает «Сервер снова доступен» и скрывается;
- когда сам интернет offline, серверная плашка не дублирует NetworkStatusBanner;
- /api/health исключается из Service Worker API-кэша.

Распаковать ZIP в:
D:\job\it\msm-app

Проверка:
node .\apply-v060-part1j-server-status.cjs --check

Если всё OK:
node .\apply-v060-part1j-server-status.cjs

Затем:
git diff --check

cd .\backend
npm run build

cd ..\frontend
npm run build

Тест backend:
- приложение открыто;
- остановить backend на 3002, интернет не отключать;
- через несколько секунд должна появиться плашка сервера;
- снова запустить backend;
- должна появиться «Сервер снова доступен» и исчезнуть.
