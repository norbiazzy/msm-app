v0.6.0 Part 1N-F1 — создание доверенности и ЭТРН сразу со структурированными полями

Что добавляет:

В сделке для менеджера появляется блок:
«Документы и логистика»

Кнопки:
- + Доверенность
- + ЭТРН

Обе формы используют те же TaskStructuredFields,
которые уже применяются при возврате задачи.

Доверенность создаётся сразу с:
- Поставщик / завод
- От какой организации
- На кого доверенность
- № входящего счёта
- Дата
- Что получаем
- Водитель / водители
- Комментарий по водителю

ЭТРН создаётся сразу с:
- № доверенности
- Покупатель
- Перевозчик
- Контакты перевозчика
- Логист
- Телефон логиста
- Водитель
- Машина
- Прицеп
- Адрес погрузки
- Адрес выгрузки
- Дата перевозки
- Груз / материал

Все поля пока необязательные.

После «Отправить бухгалтерии»:
- создаётся Task со статусом NEW;
- details сохраняются сразу;
- если есть документы, запускается background upload;
- файлы имеют TASK_ATTACHMENT_<taskId>;
- пользователь переходит в «Задачи»;
- прогресс виден на карточке этой задачи;
- бухгалтер видит те же структурированные данные.

Prisma migration НЕ нужна — Task.details уже добавлен ранее.

Установка:
1. Распаковать ZIP в:
D:\job\it\msm-app

2. Проверка:
node .\apply-v060-part1n-f1-create-poa-etrn.cjs --check

3. Если OK:
node .\apply-v060-part1n-f1-create-poa-etrn.cjs

4. Проверить:
git diff --check

5. Backend:
cd .\backend
npm run build

6. Frontend:
cd ..\frontend
npm run build
