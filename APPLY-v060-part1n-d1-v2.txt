v0.6.0 Part 1N-D1 v2 — универсальный возврат обычных задач

Старый Part 1N-D1 НЕ использовать.

Что делает:
- убирает жёсткий список POWER_OF_ATTORNEY / ETRN;
- любая обычная задача через TaskDetail автоматически получает:
  NEW / IN_PROGRESS -> «Вернуть менеджеру»;
  NEED_DATA -> исправление + повторная отправка;
  добавление новых файлов через ManagerResubmitPanel;
- используется та же Task, дубль не создаётся.

Исключения:
- ISSUE_CLIENT_INVOICE — свой сценарий счёта;
- PAY_SUPPLIER — свой SupplierPaymentTask / SupplierPurchase.

v2 дополнительно:
- бухгалтерский блок ищется строго только до ReturnToManagerPanel;
- менеджерский блок ищется строго только до ManagerResubmitPanel;
- соседний список типов больше не может быть заменён ошибочно.

Backend / Prisma не меняются.
