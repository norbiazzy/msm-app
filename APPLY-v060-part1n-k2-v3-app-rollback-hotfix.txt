Part 1N-K2 v3 — App.tsx rollback hotfix

Причина:
K2 v3 физически удалил старую кнопку возврата внутри JSX-условия,
из-за чего осталась пустая JSX-ветка и frontend перестал парситься.

Что делает hotfix:
- находит последний backup:
  frontend/src/App.tsx.before-part1n-k2-v3-*
- восстанавливает ТОЛЬКО App.tsx из этого backup
- текущий сломанный App.tsx сохраняет отдельно как:
  App.tsx.broken-after-k2-v3-*
- PurchasesBlock.tsx НЕ откатывает
  (единый возврат PAY_SUPPLIER остаётся)
- backend не меняет
- Prisma migration не нужна

Запуск:
cd D:\job\it\msm-app

node .\apply-v060-part1n-k2-v3-app-rollback-hotfix.cjs --check
node .\apply-v060-part1n-k2-v3-app-rollback-hotfix.cjs

cd .\frontend
npm run build
