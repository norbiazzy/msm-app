MSM v0.5.7 — стабилизация текущего цикла

Что входит:
- убран лишний блок «От кого выставлен» из верхней сводки сделки;
- статус CONFIRMED теперь означает «Счёт готов», без отдельного согласования с заказчиком;
- готовый клиентский счёт можно открыть прямо сверху сделки и из версии счёта;
- блок входящих счетов скрыт, если счетов нет; при нескольких поставщиках показывает актуальный счёт каждого поставщика;
- входящие счета по поставщикам остаются редактируемыми в карточках закупок;
- полная оплата поставщику закрывает задачу независимо от наличия печати на платёжке;
- менеджер видит платёжные документы и их статус;
- если платёжка без печати, менеджер может отдельно запросить вариант с печатью;
- для «Оплаты с остатка» платёжка не требуется;
- запрос платёжки с печатью создаёт отдельную задачу бухгалтерии;
- добавлены подписи в историю событий.

Миграция Prisma не требуется.

Применение:
  git apply --check .\update-v057-stabilize.patch
  git apply .\update-v057-stabilize.patch
  git diff --check
  npm run build
